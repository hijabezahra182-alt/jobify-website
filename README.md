## 📌 About The Project

Jobify 2.0 is a frontend web project that simulates a modern job discovery platform.

Users can search through opportunities, filter jobs by type, save interesting positions, and manage their saved opportunities directly in the browser.

The project focuses on:

* Clean UI/UX
* Responsive design
* Practical JavaScript functionality
* Local browser storage
* Real-world frontend development patterns

---

## 🚀 Features

### 🔎 Job Search

Search opportunities by:

* Job title
* Company
* Skill
* Location
* Work type

### 🗂️ Job Filters

Filter opportunities by:

* All

## ⚙️ How It Works

### 1. Search

Users enter a keyword or location and Jobify searches the available opportunities.

### 2. Filter

Users can narrow results using job-type filters.

### 3. Save

Clicking the heart button saves a job.

The saved job ID is stored in the browser's LocalStorage.

### 4. Manage

Saved opportunities appear in the **Saved Jobs** section where users can remove them whenever they want.
